# 🪑 Manakamana Furniture

A full-stack e-commerce web application for browsing and purchasing furniture online. The project provides user authentication, product browsing, shopping cart functionality, checkout, and eSewa Sandbox payment integration.

## Features

- User registration and login
- Product catalog
- Shopping cart
- Checkout process
- eSewa Sandbox payment integration
- Order management
- Responsive user interface

## Installation

1. Clone the repository.

```bash
git clone https://github.com/YOUR_USERNAME/REPOSITORY_NAME.git
```

2. Copy the project folder into:

```
xampp/htdocs/
```

3. Start **Apache** and **MySQL** using XAMPP.

4. Create a MySQL database.

5. Import the provided SQL file into phpMyAdmin.

6. Update the database credentials in `config.php` if necessary.

7. Open your browser and visit:

```
http://localhost/manakamana-furniture/
```
For my port 8080
```
http://localhost:8080/manakamana-furniture/
```
